# 🏆 Bracket Tournament Manager

Gestor de torneos de doble eliminación - 100% local, sin necesidad de internet.

## 🚀 Inicio Rápido

### Para Usar la Aplicación:
**Doble click en:** `Abrir_Aplicacion.bat`

O manualmente abre: `dist/index.html`
